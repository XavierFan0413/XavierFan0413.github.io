    THE ENGINEERING QUESTION
    Approval must survive a retry.
    It must not survive a changed request.
    This small deterministic gate binds review to the actor, tenant, tool arguments and policy version. It checks the authoritative record and records a synthetic effect once per idempotency key.
    The same JavaScript module powers this interface and the Node test suite. The ten scenarios are development fixtures, not a security benchmark.
    Trust boundary: a real service must supply authenticated actor context, protect approval storage, and atomically reserve an idempotency key with an outbox transaction. This browser simulation provides none of those production guarantees. It does not judge whether message content is correct or safe.
